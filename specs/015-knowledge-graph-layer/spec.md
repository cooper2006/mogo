# Feature Specification: Knowledge Graph Layer

**Feature Branch**: `015-knowledge-graph-layer`

**Created**: 2026-07-08

**Status**: Draft

**Input**: 补齐规划文档清单 11（P2 规模化生态）"知识图谱层"（知识库《企业级 Agent 架构》六层地基）：在文档 RAG 之上补充结构化知识图谱，支持跨文档实体/关系推理，提升复杂问题的多跳问答与一致性校验。

## User Scenarios & Testing *(mandatory)*

用户故事按优先级排列，每个独立可交付、可测试。

### User Story 1 (P1) — 知识图谱构建（实体/关系抽取）

从企业文档/数据中抽取实体与关系，构建结构化知识图谱（节点=实体，边=关系）；图谱可查询、可遍历。

**Acceptance Scenarios:**
- 文档抽取 → 实体（人/组织/产品/事件）与关系（隶属/负责/引用）入图谱
- 图谱可查询某实体的邻居
- 增量更新 → 新文档抽取合并，不破坏既有图谱

### User Story 2 (P1) — 多跳推理问答

复杂问题走图谱多跳推理（如"X 的产品负责人所在团队的负责人是谁"），答案带推理路径。

**Acceptance Scenarios:**
- 多跳问题 → 沿图谱路径推导，答案附推理路径
- 路径断裂 → 明确"图谱中无该关系"，不臆测
- 单跳问题 → 直接命中

### User Story 3 (P2) — 一致性校验

利用图谱一致性约束（如关系互斥/传递性）检测文档/数据矛盾，标记冲突。

**Acceptance Scenarios:**
- 实体属性矛盾（两处记录不一致）→ 图谱标记冲突
- 关系违背约束 → 提示
- 一致 → 不标记

### Notes / Assumptions
- 本特性补齐规划文档清单 11（P2 规模化生态，后置），属缺口新特性
- 现状：MOVO 有文档 RAG（特性 005），知识图谱层是其结构化扩展
- 与特性 005（knowledge-rag）的关系：图谱补充 RAG 的结构化推理，二者并行
- 与特性 014（业务语义索引）的关系：业务实体可纳入图谱节点，跨系统实体对齐
- 图谱存储（图数据库 vs MongoDB 图模拟）需 clarify；首期可先用 MongoDB 邻接结构，量大再迁图数据库
- 实体/关系 schema 领域相关，需按业务定

## Functional Requirements

- FR-1: 从文档/数据抽取实体与关系构建知识图谱；**实体类型 = 人/组织/产品/事件，关系类型 = 隶属/负责/引用/关联（企业内通用 schema，`schema.py` 可扩展）**
- FR-2: 图谱可查询实体邻居、可遍历路径；**查询入口 = 按实体 ID 查邻居 + 按关系类型过滤 + 按实体 ID 遍历路径（均可指定跳数）**
- FR-3: 增量抽取合并，不破坏既有图谱；**合并策略 = 同实体多来源属性合并（冲突属性标记 `conflicted`，保留多值，不覆盖）**
- FR-4: 多跳推理问答，答案附推理路径；**"跳" = 一次关系遍历，默认上限 3 跳（`kg_max_hops` 可配），防查询爆炸**
- FR-5: 路径断裂明确标注，不臆测；**断裂判定 = 某跳关系缺失即断，标注形式 = 列出断在第几跳及缺失的关系**
- FR-6: 一致性约束检测矛盾；**约束种类 = 互斥（同实体两类互斥属性）+ 传递（A→B→C 则 A→C）+ 基数（关系端点数量上限）**
- FR-7: 实体/关系 schema 可配置（按领域）
- FR-8: 图谱访问受 001 治理层权限约束；**图谱权限码 `kg:read`（001 权限码 resource 含图谱维度）**
- FR-9: 与 005 RAG 并行，二者结果可融合；**融合裁决 = 图谱推理与 RAG 检索结果并列返回并标注来源，冲突时以图谱结构化路径优先展示（不静默择一）**
- FR-10: **首期存储 = MongoDB 邻接（`kg_nodes` + `kg_edges`），迁移 Neo4j 阈值 = 节点 > 50 万 或 查询 p95 > 500ms**
- FR-11: **多跳查询防环：命中环（A→B→A）时按跳数上限截断，不无限遍历**
- FR-12: **实体抽取置信度门槛：低置信实体不入图（阈值可配），避免抽取噪声污染图谱**
- FR-13: **图谱节点引用 014 业务实体：走 `kg_nodes.source_ref` 指针引用 `biz_entities`，不做数据复制**
- FR-14: **矛盾检测命中（FR-6）后：仅标记"冲突"并保留可查询，不阻断查询（结果标注冲突提示）**

## Non-Goals
- 不替代文档 RAG（图谱是结构化补充，文本检索仍走 RAG）
- 不实现通用图数据库（首期可用 MongoDB 模拟，量大再迁）
- 不实现图谱自动维护/清理策略
- 不改变 005 既有 RAG 契约

## Success Criteria
- 实体/关系抽取入图谱可查询
- 多跳推理答案 100% 附路径
- 路径断裂 0 臆测
- 矛盾 100% 标记
