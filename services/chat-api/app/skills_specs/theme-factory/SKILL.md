# 主题工厂技能

本技能提供一组精选的专业字体与配色主题，每套主题都配有精心挑选的色板与字体搭配。选定主题后，即可套用到任何交付物上。

## 用途

如需为演示幻灯片套用统一、专业的样式，请使用本技能。每套主题包含：
- 带十六进制色值的协调色板
- 用于标题与正文的互补字体搭配
- 适合不同场景与受众的鲜明视觉识别

## 使用说明

要为幻灯片或其他交付物套用样式：

1. **展示主题一览**：显示 `theme-showcase.pdf` 文件，让用户直观看到全部可用主题。不要对它做任何修改，仅展示供查看。
2. **询问用户选择**：询问要为该演示文稿套用哪套主题
3. **等待用户选定**：获得对所选主题的明确确认
4. **套用主题**：主题确定后，把所选主题的配色与字体套用到演示文稿/交付物上

以下 10 套主题可用，每套均在 `theme-showcase.pdf` 中展示：

1. **Ocean Depths（深海）** —— 专业沉稳的海洋主题
2. **Sunset Boulevard（日落大道）** —— 温暖明艳的日落色调
3. **Forest Canopy（林冠）** —— 自然扎实的大地色系
4. **Modern Minimalist（现代极简）** —— 干净利落的当代灰阶
5. **Golden Hour（黄金时刻）** —— 浓郁温暖的秋日色板
6. **Arctic Frost（极地霜雪）** —— 清冷明快的冬感主题
7. **Desert Rose（沙漠玫瑰）** —— 柔和精致的灰调暖色
8. **Tech Innovation（科技创新）** —— 大胆现代的科技美学
9. **Botanical Garden（植物园）** —— 清新有机的花园配色
10. **Midnight Galaxy（午夜星河）** —— 戏剧化的深邃宇宙色调

## 主题细节

每套主题在 `themes/` 目录中定义，包含完整规格：
- 带十六进制色值的协调色板
- 用于标题与正文的互补字体搭配
- 适合不同场景与受众的鲜明视觉识别

## 套用流程

选定偏好的主题后：
1. 从 `themes/` 目录读取对应的主题文件
2. 在整个演示文稿中一致地套用指定的配色与字体
3. 确保对比度与可读性合适
4. 在所有幻灯片上保持该主题的视觉识别

## 创建自定义主题
若现有主题都不适用于某个交付物，可创建自定义主题。根据提供的输入，生成一套与上述主题类似的新主题。为其取一个类似的名称，描述该字体/配色组合所代表的风格。依据给出的基础描述选择恰当的配色与字体。生成主题后先展示以供审阅与确认，随后按上述方式套用该主题。
