# 值班交接模板（024 T100 / FR-052）

每次值班交接 MUST 使用本模板记录，**在办事项未闭环不得空项交接**。
交接后双方确认，模板归档到 `deploy/runbook/handoffs/<交接日期>.md`。

```markdown
# 值班交接 — <交接日期> <时段>

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 交班人 | <姓名 / 值班编号> |
| 接班人 | <姓名 / 值班编号> |
| 交接时间 | <UTC/本地 ISO> |
| 接班时段 | <起> ~ <止>（须与 oncall-roster.yml 一致） |
| 交班时段 | <起> ~ <止> |
| 值班等级 | <L0 / L1> |
| 是否异常交接 | <是 / 否（异常需在下方"遗留问题"列明）> |

## 环境状态

| 项 | 状态 | 备注 |
| --- | --- | --- |
| 全部服务健康 | <是 / 否 / 有告警> | 异常项列出 |
| 最近备份成功 | <时间> | 无则写"未成功：<原因>" |
| 灰度档位 | <stable / 1% / 10% / 50% / 100%> | 未结束灰度写当前档位 |
| 活跃变更 | <PR / 变更单> | 在办变更链接 |

## 在办事项

| # | 事项 | 属主 | 状态 | 下一步 | 截止 |
| --- | --- | --- | --- | --- | --- |
| 1 | <描述 + 工单/事故单号> | <人> | <进行中 / 待跟进 / 待验证> | <具体动作> | <时间> |
| 2 | ... | ... | ... | ... | ... |

> **未闭环事项交接**：接班人 MUST 在接班时段内推进；无法推进须在接班 30 分钟内升级
> （见 `deploy/runbook/alert-escalation.md`）。

## 告警 / 事件回顾

- 本班告警数：<N>（P0 <n> / P1 <n> / P2 <n>）
- 未关闭告警：<N> — 列明细 + 负责人 + 预计关闭时间
- 事件单号：<incident-id>（有则填）

## 钥匙 / 凭据 / 访问

| 项 | 交接内容 | 存放位置 |
| --- | --- | --- |
| 值班手机 / 呼台 | <号码> | <位置> |
| IM 群管理员权限 | <是 / 否> | — |
| 备份/恢复密钥访问 | <位置 + 使用说明> | 见 backup-key-management.md |
| 故障切换密钥访问 | <位置 + 使用说明> | 见 failover-runbook.md §0 |

## 已知问题 / 注意事项

- <已知但未修复的问题 + 临时绕行措施>
- <值班经验 / 需重点关注的服务>

## 交接确认

| 角色 | 姓名 | 时间 | 签名 / 确认方式 |
| --- | --- | --- | --- |
| 交班人 |  |  |  |
| 接班人 |  |  |  |
| （必要时）值班经理 |  |  |  |

## 附：交接后 15 分钟回检

- [ ] 接班人已确认在办事项 1..N
- [ ] 告警渠道正常（`./mogo notify info "值班交接完成"` 收到）
- [ ] 值班联系方式可达（`./mogo oncall-check --now` 或 oncall-check.sh 对应时段）
```

## 使用说明

1. 复制上述模板到 `deploy/runbook/handoffs/<交接日期>.md` 填写，随交接完成归档。
2. **在办事项为空也必须在 `交接确认` 表签字**——交接确认不可省略。
3. 异常交接（事故中 / 服务降级中）必须在「环境状态」「在办事项」「已知问题」三处如实标注。
4. 交接记录纳入下次 DR 演练（T088/T081）复盘材料。
