# 韧性 / 混沌工程演练计划（Resilience & Chaos Plan）

> 对应审计项：QF-505（故障注入清单 + 稳态假设）、QF-506（中止条件）、QF-507（演练报告结构）。
> 本文档列出 mogo 后端（admin-api / chat-api / document-parser）的**故障注入清单、稳态假设与中止条件**，作为生产环境演练的基线。本地离线环境（ServBay/OrbStack 提供的 MongoDB，redis/weaviate 为可选降级依赖）无法完成全部真实注入，需在具备完整运行时与生产级数据量的环境执行注入演练。

## 1. 依赖与故障域（真实依赖拓扑）

| 依赖 | 角色 | 本地状态 | 故障模式 |
| --- | --- | --- | --- |
| MongoDB (`MONGODB_URI`, 默认 127.0.0.1:27017) | 主数据存储（租户、会话、技能、反馈） | 已起（ServBay/OrbStack） | 连接断开、主从切换、慢查询、磁盘满 |
| Redis (`DSH_KERNEL_REDIS_URL`) | 多副本 kernel state 共享（可选） | 默认空，功能降级 | 不可用 → kernel 无法跨副本 fork |
| Weaviate (`WEAVIATE_*`) | 向量检索（可选） | 未配置则降级 | 不可用 → 检索类接口降级 |
| LLM 网关（dashscope / openai / qwen） | 对话与推理 | 需 API key | 限流 429、5xx、超时、DNS 失败 |
| document-parser API | 文档解析 | `DOC_PARSER_API_URL` | 5xx、超时、队列积压 |
| Admin API / Chat API 互访 | `ADMIN_API_BASE_URL` / `BACKEND_INTERNAL_BASE_URL` | 本地 8100/8000 | 下游慢/不可用 |

## 2. 故障注入清单（Injection Catalog）

| 注入项 | 方法 | 预期稳态行为 |
| --- | --- | --- |
| 依赖故障：Mongo 断连 | 网络拦截 27017 / kill 实例 | 连接池快速失败，错误在超时内返回，不无限挂起；恢复后自动重连 |
| 实例被杀 | `kill -9` 单副本 | 负载均衡绕行至健康副本；会话状态由 Mongo 持久化，不丢数据 |
| 网络分区 | 副本间隔离 | 写入在 quorum 失败时报错，读取降级到可用副本 |
| 磁盘满 | 写满 Mongo 数据卷 | 写入返回明确错误，读路径不受影响；监控触发告警 |
| 下游延时放大 3× | 在 LLM/parser 前加延迟代理 | 接口 P99 不超过上游超时；超时后返回降级结果或明确错误 |
| 下游 5xx / 连接拒绝 | 故障代理返回 5xx | 重试序列 + 熔断在 10s 内生效；恢复后自动恢复，无请求堆积 |
| 按比例错误注入 50% | 故障代理 | 降级分支被走到；核心功能成功率仍达 SLO |
| DNS 解析失败 / 连接超时 | 污染 DNS 或拦截 | 客户端在配置超时内失败，错误日志含依赖名与类型，不无限重连 |
| 时钟偏移 ±5min | 调整本地时钟 | 会话有效期/超时判定可解释；锁租约与幂等窗口不产生重复执行 |
| 缓存失效 | 清空本地/Redis 缓存 | 写后失效策略一致，读回新值延迟在约定秒数内；空值缓存防穿透 |

## 3. 稳态假设（Steady-State Hypotheses）

- **成功率**：核心非 LLM 接口（健康、租户管理、技能目录、登录态校验）成功率 ≥ 99.5%。
- **延迟 SLO**：P99 租户数据访问路径 ≤ 已声明目标（300ms）；P99/P50 比值 ≤ 5×。
- **错误预算**：核心接口月度错误预算按 SLO 推导；演练期间消耗速率可观测。
- **不变量**：租户数据隔离不被破坏（A 租户在故障下读不到 B 租户数据）；会话持久化不丢。

## 4. 中止条件（Abort Criteria）

满足任一即**立即停止注入**并记录时间戳与触发原因：

1. 核心接口成功率跌破 **99.0%**（或 SLO 的 50% 错误预算耗尽）。
2. P99 延迟超过 SLO 目标 **2×** 且持续 > 30s。
3. 出现进程 OOM、崩溃或副本全不可达。
4. 数据一致性校验失败（跨租户泄露 / 持久化丢失）。
5. 人工判定风险不可控。

## 5. 演练报告结构（每次演练产出）

- 假设（hypothesis）与预期稳态。
- 注入参数（项、强度、时长、目标副本）。
- 观测指标数据 / 截图（成功率、P50/P95/P99、吞吐、资源占用）。
- 假设是否被证伪（falsified / upheld）。
- 后续修复项与负责人、截止日期。
